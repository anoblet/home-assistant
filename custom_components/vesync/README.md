# VeSync Custom Component

This folder contains the custom Home Assistant integration for VeSync.

Canonical documentation lives under:

- `docs/custom-components/vesync.md` (user-facing overview, entities, services, troubleshooting)
- `docs/custom-components/vesync-pyvesync-coverage.md` (auditable feature/entity mapping; pinned to `pyvesync==3.3.3`)

The Home Assistant service schemas are defined in `custom_components/vesync/services.yaml`.
